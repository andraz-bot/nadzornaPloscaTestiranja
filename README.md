# Nadzorna plošča testiranja

Moderna namizna aplikacija (Electron) za enostavno nalaganje, zagon, spremljanje in analizo testiranj ter upravljanje projektov.

## Glavne funkcije

* **Upravljanje projektov:** Enostavno dodajanje projektov preko ZIP datotek ali map.
* **Vertikalna nit (Pipeline):** Vizualni prikaz napredovanja skozi celotni cikel testiranja s pomočjo dinamičnega traku v stranski vrstici.
* **Konzola v živo:** Dinamičen prikaz izvajanja testov v realnem času z možnostjo izvoza zapisnikov (logov).
* **Zgodovina in poročila:** Pregled preteklih izvajanj in rezultatov testov.
* **Prilagodljivost:** Podpora za več jezikov (slovenščina, angleščina) in različne vizualne teme.
* **Interaktivni vodič:** Vgrajen začetni vodič za hitro spoznavanje aplikacije.

## Uporabljene tehnologije

* [Electron](https://www.electronjs.org/) - Okvir za namizne aplikacije
* HTML5 / CSS3 / JavaScript - Uporabniški vmesnik

## Namestitev in zagon

Za zagon aplikacije v lokalnem okolju sledite tem korakom:

1. **Klonirajte repozitorij:**
   ```bash
   git clone [https://github.com/andraz-bot/nadzornaPloscaTestiranja.git](https://github.com/andraz-bot/nadzornaPloscaTestiranja.git)

2. **Pomaknite se v mapo projekta:**
   cd nadzornaPloscaTestiranja

3. **Namestite odvisnosti:**
   npm install

3. **Zaženite aplikacijo:**
   npm start
